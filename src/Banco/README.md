#  Sistema de Agência Bancária em Java

Projeto desenvolvido em Java para consolidar conceitos fundamentais e avançados de Programação Orientada a Objetos (POO). O sistema simula o gerenciamento de contas bancárias para Pessoas Físicas e Pessoas Jurídicas com validação de segurança via interface.

##  Tecnologias e Conceitos Utilizados
- **Abstração:Classe mãe que impede a criação de clientes genéricos.
- **Herança: Reaproveitamento de atributos estruturais entre as classes filhas.
- **Polimorfismo: Métodos de crédito extra calculados dinamicamente de acordo com o tipo de conta.
- **Interfaces**: Contrato de segurança implementado para autenticação de senhas.
- **Estruturas de Repetição e Condicionais**: Loops  e estruturas para navegação do menu e controle de vagas no banco.
- **Manipulação de Arrays de Objetos**: Vetor estruturado para armazenar as instâncias das classes filhas.
